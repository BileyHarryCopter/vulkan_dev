KEY FEATURES:
------------

✓ Automatic meshlet generation (max 64 verts, 126 triangles)
✓ Task and mesh shader pipeline support
✓ Storage buffer bindings for meshlet data
✓ Backward compatible with traditional rendering
✓ Easy to enable/disable via flag in app.cpp
✓ Comprehensive documentation

USAGE:
------

To enable meshlet rendering:
1. Open src/src/app.cpp
2. Line 77: Change "bool useMeshShaders = false;" to "true"
3. Compile shaders: cd src/src/shader && ./compile.sh
4. Build and run the application

TESTING:
--------

The implementation has been designed to be:
- Backward compatible (set useMeshShaders = false)
- Modular (changes isolated to specific components)
- Well-documented (see MESHLET_RENDERING.md)

REQUIREMENTS:
------------

- Vulkan 1.3 or later
- GPU with VK_EXT_mesh_shader support
- NVIDIA RTX 20 series or AMD RDNA 2 or newer
